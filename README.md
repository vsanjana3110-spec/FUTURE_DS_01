# FUTURE_DS_01

## Future Interns Data Science & Analytics – Task 1
### Business Sales Performance Analytics

## Project Objective

The objective of this project is to analyze business sales data to identify revenue trends, top-selling products, high-performing categories, and regional sales performance.

## Dataset

This project uses a simulated sales dataset created for learning and internship purposes.

The dataset contains information such as:
- Order ID
- Order Date
- Customer ID
- Region
- Category
- Product
- Quantity
- Unit Price
- Sales
- Profit

## Tool Used

- Microsoft Excel

## Key Performance Indicators

- Total Sales: 41,316,268.41
- Total Profit: 6,565,640.78
- Total Quantity: 3,230
- Total Orders: 720

## Key Insights

1. Electronics contributes the highest sales among all categories.
2. South region records the highest sales among the regions.
3. Laptop is the top-selling product by sales.
4. Monthly sales show noticeable fluctuations throughout the year.

## Recommendations

1. Maintain sufficient stock of high-selling electronics products.
2. Study the factors contributing to strong sales in the South region.
3. Focus marketing efforts on high-performing products while monitoring lower-performing products.
4. Investigate low-sales months and plan promotions or campaigns accordingly.

## Project Files

- `FUTURE_DS_01_Task1_Sales_Data.xlsx` – Excel workbook containing the sales data, cleaned data, KPI analysis, and dashboard.
- Dashboard – Business Sales Performance Dashboard.

## Conclusion

This project provides a business-focused analysis of sales performance using Excel, with KPIs, charts, insights, and recommendations to support data-driven decision making.
